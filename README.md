# ThinkTwice

ThinkTwice is a Terminal-based critical-thinking assessment for people aged 12 and up. It presents fictional social-media scenarios and gives feedback on reasoning, misinformation, and logical fallacies. Scenarios are generated by OpenAI from the topic guidance in `data/question_guidance.json`; they are not real news or a fixed question bank.

## Set up with Conda

From the project folder, create and activate the environment:

```bash
conda env create -f environment.yml
conda activate thinktwice
```

If you already created the `thinktwice` environment and installed the OpenAI package, just activate it.

## Set your API key

ThinkTwice uses OpenAI's `gpt-6-luna` automatically. An OpenAI API key is required, and API usage may incur charges. The key is read from your Terminal environment and is never saved in project files.

In macOS Terminal using zsh, run this command by itself:

```zsh
read -s "OPENAI_API_KEY?Paste only your OpenAI API key (input is hidden): "
```

Paste the API key at the hidden prompt and press Return. When the normal Terminal prompt appears again, run:

```zsh
export OPENAI_API_KEY
```

The key remains available only in that Terminal session. If you close the window, set it again in a new session. Never paste the key into chat or save it in this project.

## Start ThinkTwice

From the project folder, with the Conda environment active and the API key set:

```bash
python -m thinktwice
```

The assessment presents five questions in each of seven topics, one question at a time. Enter one or more answers as letters separated by commas, for example `A,B`. Selecting all correct letters and no incorrect letters is required to get a question right. A score of at least 28 out of 35 (80%) passes.

Before each topic's five questions, ThinkTwice displays a short explanation of the basic idea. It gives feedback after each answer and a category review at the end. Answers and results are scored in memory on your computer and are not sent to OpenAI or saved after the session ends. OpenAI generates each question and its answer key, so the quality of the assessment depends on the generated content.

## Privacy and provider calls

ThinkTwice sends the selected topic guidance, generation instructions, the `gpt-6-luna` model ID, and a response schema to OpenAI for each question. It does not send learner answers, names, or assessment results. It makes no model-list request. OpenAI's data handling and retention terms apply to prompts and generated content; `store: false` disables Responses application-state storage but does not disable abuse-monitoring retention. Review OpenAI's current [data controls](https://developers.openai.com/api/docs/guides/your-data) and [API pricing](https://developers.openai.com/api/docs/pricing) before use.
